# Icon Sources and Attribution

## Microsoft Fluent UI System Icons
- **Upstream Repository**: https://github.com/microsoft/fluentui-system-icons
- **License**: MIT License (full text in `assets/icons/fluent/LICENSE`)

- **Variants Used**: 20px regular and filled SVG vector icons
- **Usage**: Official user interface icons for toolbar navigation, sidebar bookmarks, context actions, menus, properties dialog, and preferences controls.

## Windows Native Shell Icons
- **Engine**: Shell COM and Win32 `SHGetFileInfoW` / `IShellItemImageFactory`
- **Source**: Running Windows Shell subsystem (Explorer system image list and file associations)
- **Caching**: Off-UI-thread background worker cache with LRU memory caching
- **Usage**: Runtime file type icons, directory glyphs, drive emblems, and registered application icons.
